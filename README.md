# הסדרות שלי

מעקב צפייה אישי בסדרות: לפי סטטוס צפייה, בלי מעקב פרקים. הממשק בעברית ובאנגלית.

**לפתיחה:** https://arbel24margalit.github.io/series-tracker/

- הנתונים נשמרים רק בדפדפן של המכשיר. אין חשבון ואין שרת.
- התמונות מגיעות מ-[TVmaze](https://www.tvmaze.com/api) (חינמי, בלי מפתח API).
- הגיבוי נעשה מההגדרות: "שמירת קובץ גיבוי" ו"שחזור מקובץ גיבוי".
- אפשר להתקין את האתר כאפליקציה בטלפון (תפריט הדפדפן ← "הוספה למסך הבית"), והוא עובד גם בלי אינטרנט.

## אפליקציית הטלוויזיה (tv.apk)

- קישור ל-Netflix, YouTube, yes ושירותים מוכרים נפתח באפליקציה של השירות.
- כל קישור אחר נפתח ב"מסך צפייה" בתוך האפליקציה: מסך מלא, בלי חלונות קופצים, עם חסימת פרסומות בסיסית לפי `ad-hosts.txt`. אפשר לערוך את הקובץ בלי להתקין מחדש.
- "חזור" יוצא ממסך מלא, חוזר אחורה בדף, ובדף הראשון חוזר לרשימה.
- עדכון עצמי: בפתיחה האפליקציה בודקת ב-`version.json` אם יש גרסה חדשה ומציעה לעדכן.
- החתימה קבועה (מפתח בהגדרות הסודיות של המאגר: `TV_KEYSTORE_B64`, `TV_KEYSTORE_PASS`), כך שעדכונים מותקנים מעל הגרסה הקיימת.

## הרצה מקומית

```bash
python3 -m http.server 8000
```
