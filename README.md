# הסדרות שלי

מעקב צפייה אישי בסדרות: לפי סטטוס צפייה, בלי מעקב פרקים. הממשק בעברית ובאנגלית.

**לפתיחה:** https://arbel24margalit.github.io/series-tracker/

- הנתונים נשמרים רק בדפדפן של המכשיר. אין חשבון ואין שרת.
- התמונות מגיעות מ-[TVmaze](https://www.tvmaze.com/api) (חינמי, בלי מפתח API).
- הגיבוי נעשה מההגדרות: "שמירת קובץ גיבוי" ו"שחזור מקובץ גיבוי".
- אפשר להתקין את האתר כאפליקציה בטלפון (תפריט הדפדפן ← "הוספה למסך הבית"), והוא עובד גם בלי אינטרנט.

## הרצה מקומית

python3 -m http.server 8000
# http://localhost:8000
